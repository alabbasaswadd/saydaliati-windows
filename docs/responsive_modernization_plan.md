# خطة التجاوب والتحديث العصري — صيدليتي (ويندوز)

> نتيجة مسح شامل للواجهات بتاريخ 2026-10-13. الهدف: تحويل التطبيق من أنماط
> موبايل مفروشة على عرض سطح المكتب إلى واجهات ويندوز عصرية متجاوبة.

---

## أولًا: ملاحظات الاستكشاف (الوضع الحالي)

### الشِل والتنقل
- `desktop_shell.dart` يسلّم للصفحة كامل العرض المتبقي **بلا أي قيد أو توسيط** — كل صفحة تمتد 1600–1900px.
- لا يوجد أي نظام نقاط توقف (breakpoints) في المشروع؛ الاستثناء الوحيد `auth_scaffold.dart:27` (شاشة الدخول المقسومة).
- `AppSizes.maxContentWidth = 560` معرّف في `app_spacing.dart:58` و**غير مستخدم إطلاقًا**.
- كود موبايل ميت ما زال في الشجرة: `main_shell.dart` (شريط تنقل سفلي، 310 سطرًا) و`more_page.dart` — غير موصولين بالراوتر.
- فتح التقارير من الرئيسية (`home_page.dart:135`) ومركز التقارير (`reports_hub_page.dart:19`) يتم بـ `Navigator.push` على الجذر → **ينفصل تظليل الشريط الجانبي عن الصفحة المعروضة**.

### التقارير (9 شاشات)
- كلها عمود واحد ممتد بكامل العرض، مبنية على `ReportList` (`report_list.dart:41`) الموصوف صراحةً بأنه **"Mobile-first"**: بيانات جدولية تُعرض كبطاقات متراصة بلا أعمدة ولا فرز ولا محاذاة، وتُبنى كل الصفوف دفعة واحدة (بلا `builder`) حتى لو كانت آلافًا.
- KPIs ممتدة: `StatTile` **واحد** بعرض النافذة كاملة في `purchases_report_page.dart:63` و`stocktake_report_page.dart:140`؛ و`medicine_report_page.dart:117` يثبّت شبكة بعمودين → بطاقات عملاقة على 1600px.
- كل الفلاتر (الفترة/العملة/النافذة الزمنية) مخفية خلف `endDrawer` منزلق (`period_side_sheet.dart`, `filter_side_sheet.dart`) — درج كامل الارتفاع لأجل 4 خيارات.
- تقرير الوصفات يستخدم أكورديون `ExpansionTile` (`prescriptions_report_page.dart:106`) بدل نمط رئيسي-تفصيلي.

### شاشات العمليات
- قوائم `ListTile` ممتدة بكامل العرض والعنوان وزر الحذف بينهما ~1500px: المخزون (`stock_page.dart:53`)، العملاء (`customers_page.dart:98`)، الموردون، قائمة المبيعات، المشتريات، الفواتير المعلقة، حركات المخزون، الأدوية، الإعدادات.
- زر عائم FAB كوسيلة الإنشاء الوحيدة (المخزون، المشتريات، العملاء، الموردون، الأدوية) والسحب-للتحديث كوسيلة التحديث — أنماط لمس لا تناسب الماوس.
- شرائح سفلية `showModalBottomSheet` على سطح المكتب: `catalog_detail_page.dart:31`، `currencies_page.dart:103`، `tutorial_help.dart:31`.
- النماذج شاشات كاملة بعمود واحد: `medicine_form_page.dart` (~8 حقول بارتفاع 54px وعرض 1500px)، `add_stock_page.dart` — مرشّحة لعمودين أو حوار.
- صفحات التفاصيل (بيع/شراء/دواء) تفتح كصفحة كاملة ممتدة بدل لوحة جانبية أو حوار.
- `AppButton` يجعل `fullWidth: true` افتراضيًا (`app_button.dart:151`) + الثيم يفرض ارتفاع 50 → أزرار حفظ بعرض 1500px في كل مكان.
- نقطة البيع وإنشاء المشتريات: الأفضل حالًا (تستخدمان الغريد الموحّد الجديد)، لكن شريط الملخص سفلي ممتد مع زر حفظ بنصف العرض — لوحة جانبية أنسب على الشاشات العريضة.
- الرئيسية: `LayoutBuilder` موجود لكن سقف الأعمدة مثبت عند 4، وهي مُطلق اختصارات لا لوحة معلومات (7 من 12 بلاطة تسبب انفصال الشريط الجانبي).

### الثيم
- لا `visualDensity` ولا ثيم شريط تمرير ولا hover/focus ولا حد أقصى لعرض الحوارات ولا `dataTableTheme` — كله افتراضات موبايل.
- `design_tokens.dart` كتالوج تعليقات فقط؛ لا رموز لنقاط التوقف أو عرض المحتوى أو ارتفاع صفوف الجداول.

### الأسس الجيدة الموجودة للبناء عليها
- `shared/widgets/grids/app_editable_grid.dart` — الغريد الموحّد (أعمدة مرنة/ثابتة، رأس ثابت، تمرير أفقي تحت `minWidth`، خلايا تحرير) — مستخدم حاليًا في فاتورتي المبيعات والمشتريات فقط.
- `home_page.dart:92` (تدرّج أعمدة بالعرض)، `auth_scaffold.dart` (نقطة التوقف الوحيدة)، `AppDesktopSizes` (المكان الصحيح لإضافة الرموز الجديدة).

## ثانيًا: الخطة

### المرحلة 0 — الأساس المشترك (تُبنى مرة وتخدم كل الشاشات)
1. **نظام تجاوب موحّد** في `core/theme`: نقاط توقف (ضيق < 900 / متوسط / عريض ≥ 1280) + امتداد `context.isWide` + تفعيل حد أقصى لعرض المحتوى.
2. **ثيم سطح مكتب**: `visualDensity` مدمجة، شريط تمرير ظاهر، hover للصفوف، عرض أقصى للحوارات، وإلغاء `fullWidth: true` الافتراضي في `AppButton`.
3. **`AppDataGrid` للقراءة** فوق الغريد الموحّد: أعمدة حقيقية + فرز بالنقر على الرأس + بناء كسول — ليحل محل `ReportList` في التقارير والقوائم.
4. **صف KPI متجاوب**: بطاقات بعرض أدنى/أقصى داخل `Wrap` بدل `Expanded` الممتد.
5. **شريط فلاتر مضمّن** أعلى المحتوى (chips للفترة/العملة/التصنيف)؛ الدرج يبقى للشاشة الضيقة فقط.
6. **أنماط سطح المكتب**: زر «جديد» بشريط الأدوات بدل FAB، زر تحديث بدل السحب، حوارات مركزية بدل الشرائح السفلية.
7. **تنظيف**: حذف `main_shell.dart` و`more_page.dart`، وتحويل فتح التقارير إلى `context.go` لإصلاح انفصال الشريط الجانبي.

### المرحلة 1 — التقارير

| الشاشة | التغيير |
|---|---|
| مركز التقارير | شبكة بطاقات 2–4 أعمدة حسب العرض بدل 7 صفوف ممتدة |
| المبيعات، الأرباح، المشتريات، الجرد، المخزون | KPIs بصف متجاوب + جدول `AppDataGrid` قابل للفرز بدل البطاقات + فلتر الفترة/العملة كشريط مضمّن |
| الصلاحية | التبويبان كأزرار مقسمة + جدول، وفلتر النافذة الزمنية chips |
| الوصفات | رئيسي-تفصيلي: جدول فواتير + لوحة تفاصيل جانبية بدل الأكورديون |
| تقرير الدواء | شبكة KPI متجاوبة بدل العمودين المثبتين |

### المرحلة 2 — العمليات

| الشاشة | التغيير |
|---|---|
| قوائم: المخزون، العملاء، الموردون، المبيعات، المشتريات، المعلقة، الحركات، الأدوية | جداول بأعمدة + بحث وفلاتر بشريط علوي + «جديد» بالشريط بدل FAB |
| نقطة البيع + إنشاء مشتريات | لوحة جانبية للملخص/الدفع/الحفظ على الشاشات العريضة بدل الشريط السفلي |
| تفاصيل بيع/شراء/دواء | لوحة بجانب القائمة أو حوار بدل صفحة كاملة |
| نماذج الدواء وإضافة المخزون | عمودان عند العرض الكافي + حد أقصى للعرض |
| الرئيسية | رفع سقف الأعمدة + KPIs فعلية لتصبح لوحة معلومات |

### المرحلة 3 — اللمسات العصرية
Hover وتظليل تحديد للصفوف، كثافة مريحة للماوس، رفع طفيف لحجم الخط على الشاشات الكبيرة، وتعميم انتقالات `FadeSlideIn` بهدوء.
